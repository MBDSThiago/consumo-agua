💧 Consumo de Água Residencial

Sistema desenvolvido em Python para classificar o consumo de água de diferentes tipos de imóveis e apresentar alertas de acordo com o consumo mensal.

🎯 Objetivo:

O programa pergunta o imóvel e o consumo mensal de água em (m³), classificando o consumo como econômico, moderado ou excessivo.

💻 Como executar:

1. Tenha o --Python 3.10 ou superior-- instalado.

2. Baixe o repositório.

3. Abra o projeto no Visual Studio Code.

4. Execute o arquivo Python.

5. Informe o tipo de imóvel e o consumo mensal quando solicitado.
